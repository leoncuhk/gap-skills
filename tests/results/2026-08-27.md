### Standard end-to-end MVP

An initial 0.3.0 run against the invitation fixture correctly selected Standard, inspected repository rules, kept intent and plan in the conversation, produced a failing test signal before implementation, changed only source and tests, and passed 9/9 visible tests plus the original 3/3 evaluator-held checks.

The run also exposed three failures that repository structure checks had not found:

- independent review infrastructure was unavailable, but the session waited instead of immediately falling back to labeled self-review;
- the session consumed 81,947 tokens and required interruption before a final delivery report;
- review found one unowned behavior: creating another invitation after acceptance silently returned the accepted record.

Version 0.3.1 adds a one-attempt reviewer fallback, bounded repair-loop reporting, and a fourth evaluator-held check that requires accepted identities to be rejected. The baseline fixture fails the hidden evaluator and the known-green reference solution passes all four checks.

A fresh 0.3.1 run against the clean fixture completed without intervention:

This is direct evidence that the reviewer fallback fixed the observed stall. It does not isolate the causal effect of every 0.3.1 wording change, and the zero-repair run does not exercise budget exhaustion behavior.

## Limits

The complete 20-case activation matrix is versioned in `tests/cases/activation.json` but has not been executed exhaustively across every model/harness combination; model activation is probabilistic and each release needs rerunning. Budget exhaustion and blocked-result behavior are specified but still need a deliberately unsatisfiable harness case. The standalone review run used one model and one planted fixture, and its 81,730-token cost remains high for such a small diff. The paired 10–20 task real-work pilot is intentionally future evidence, not something a repository self-test can manufacture. Therefore 0.4.0 is the strongest version supported by current evidence, not a claim of universal optimality or proven replacement superiority across all projects.
