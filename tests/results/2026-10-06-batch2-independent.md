# Gap batch 2 — independent acceptance report

Four local synthetic task artifacts pass their frozen semantic criteria: one development pair and one distinct held-out final pair. The repaired implementation passes local engineering checks. Prompt/input/requested-configuration controls are verified. Complete runtime tool-count/backend observability and browser QA remain unavailable. These are separate conclusions; this report does not declare universal protocol success or human-effort benefit.

## What was tested

The development pair resumed a workshop-capacity brief after source registrations changed. The held-out pair resumed exhibition captions after attribution and recording-year corrections, preserving an exact quotation and a substantive visitor-experience choice. Each fixture had a real locally generated checkpoint, two actual prior check receipts and then an authoritative-source change. All task content is synthetic. Both arms received identical task/source/checkpoint/feedback/experience bytes; enhanced alone received the installed gap directory.

Task prompts and criteria were frozen before implementation. The final task remained withheld until the development pair was independently graded and both code findings were disposed. Main alone launched four contexts, within the already-authorized maximum eight; acceptance launched none. There was no retry, replacement solver, extra development pair or mid-run corrective hint. Development used fixed revision 12a99151618b35fa4211aef4ee5074f454858154; final used a8965bad4e2d788662f0aa930bd793a4ff7e4eb3. The same shared prompt was normalized only for absolute workspace path, and installed mechanism bytes were independently compared with their fixed Git tree.

## Artifact results and human role

Both development arms identify two topic-specific overflow registrations despite equal total capacity and registrations. Both final arms correct facts to catalog c2, preserve the exact source quotation separately from editorial interpretation, and give real alternatives without selecting for the user. All four retain prior evidence, reject stale feedback as current authority, scope experience appropriately, and distinguish local checking from independent acceptance or external action.

Baseline manual continuation is valid: it leaves the old checkpoint explicitly historical and records current local evidence. Enhanced artifacts advance existing checkpoints to revision 2, preserve old receipt prefixes and record scoped experience rejection. This corroborates mechanism effects. Helper invocation is also declared by the enhanced agents, but no authenticated complete tool-call trace is exposed; actual helper invocation/count is not independently certified. Neither the paired artifacts nor this corroboration establishes causation or superiority.

The meaningful user choices remain intentionally open: cohort versus waitlist in development; literal voice versus editorial first impression in final. This is correct boundary preservation, not a missing permission gate. Machine evaluation cannot decide user preference or measure saved user effort here.
