# Notice

Gap adapts ideas and mechanisms from the following MIT-licensed projects and public writing, partly through its archived predecessors `defog` and `rig`. None of these authors were involved in or have endorsed this project.

- Matt Pocock — https://github.com/mattpocock/skills (MIT). Adapted: decision-frontier grilling, facts-versus-decisions separation, progressive disclosure, tracer-bullet tickets, tight red debugging loops, deep-module design, context boundaries, plan-conditioned implementation, two-axis review, and evidence-based environment retrospectives.
- Anthropic, Louis Claxton — “The AI-Native SDLC Playbook.” Adapted: durable intent/spec/plan chains, human judgment gates, organization policy as versioned agent configuration, continuous configuration evals, release authorization, and incident-to-intent feedback.
- OpenAI Cookbook — [“Using Goals in Codex”](https://developers.openai.com/cookbook/examples/codex/using_goals_in_codex) and [“Build iterative repair loops with Codex”](https://developers.openai.com/cookbook/examples/codex/build_iterative_repair_loops_with_codex) (MIT-licensed repository content). Adapted: evidence-based completion, proportional execution budgets, explicit blocked outcomes, and structured validation feedback between repair attempts.
- Thariq Shihipar — “Finding Your Unknowns.” Adapted: map/territory framing and deliberate discovery of known, tacit, and suspected unknowns.
- Neeeophytee — https://github.com/Neeeophytee/finding-unknowns-skills (MIT). Adapted: contrasting belief-driven prototypes, reaction-to-criterion synthesis, blast-radius ordering, source-as-spec reading, implementation deviations, and maintainer understanding checks.
- Nico Bailon — https://github.com/nicobailon/grill-for-unknowns (MIT). Adapted: question budgeting, fatigue handling, and material/grounded/answerable decision gates.
- Thariq Shihipar's HTML effectiveness examples and plannotator/effective-html plus dogum/html-artifacts (MIT/Apache-2.0 as applicable). Adapted: use self-contained HTML when comparison, spatial layout, diagrams, or interaction materially improve understanding; keep short linear work in Markdown.
- Shanghai AI Lab — StraTA (arXiv 2605.06642): plan-conditioned execution and plan/execution attribution; Self-Harness (arXiv 2606.09498): trace-mined, regression-gated environment evolution.

Gap's implementation contribution is one adaptive entry point that selects the smallest trustworthy path by ambiguity, scale, and risk; separates disposable task state from durable delivery evidence and environment work; and keeps guidance, automated checks, and protected controls distinct.
